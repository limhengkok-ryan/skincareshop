# Project Blueprint

## Overview

This project is a React-based e-commerce website for a skincare brand called "The Little Trooper". The website is designed to provide a sophisticated and personalized experience for users with sensitive skin. It features an AI-powered recommendation engine to help users find the right products for their specific needs.

## Implemented Features

*   **Theme and Styling:** The website uses a custom theme inspired by the provided HTML, implemented with Tailwind CSS.
*   **Routing:** The website uses `react-router-dom` for navigation.
*   **Component Library:** Using shadcn/ui for its component-based architecture.
*   **Pages:**
    *   Homepage
    *   Products
    *   Our Story
    *   The Science
    *   Testimonials
    *   Contact
    *   Login/Profile
    *   Shopping Cart

## Current Plan

The current goal is to pivot the website to focus on the AI-powered product recommendation flow. This involves the following steps:

1.  **Update Homepage:** Simplify the homepage to have a clear call-to-action (CTA) that directs users to the AI product finder.
2.  **Create AI Chat Page:** Build a new page to house the AI chat interface where users can describe their skin conditions.
3.  **Implement New Workflow:** Adjust the navigation and user flow to align with the provided diagram, prioritizing the AI recommendation engine.
